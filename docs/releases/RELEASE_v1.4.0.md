# v1.4.0 排班设置、撤销导入与模式确认

## 新增

### 导入模式不明确时询问

- 粘贴内容中同时识别到“上班”和“休息”时，弹窗询问按上班表还是休息表导入。
- 两个关键词都没有识别到时，也会弹窗询问。
- 只识别到“上班”时直接按上班表处理。
- 只识别到“休息”时直接按休息表处理。
- 判断只依赖“上班”“休息”两个关键词，不要求出现“人员”。

### 设置页面

首页新增“设置”按钮，进入排班设置页，支持：

- 清空当前班的所有排班数据；
- 按日期选择器选择开始日期和结束日期，清空指定时间段排班；
- 撤销上一次导入。

### 撤销导入

- 每次导入前自动保存当前班的排班快照。
- 每个班最多保留最近 3 次导入快照，可连续撤销 3 次。
- 没有可撤销内容时，“撤销上一次导入”按钮自动置灰。
- 撤销只恢复排班数据，不会自动删除导入过程中新增的人员或别名规则。

## 数据结构

- 新增导入历史表 `ScheduleImportHistory`。
- 数据库版本升级到 4；由于当前版本使用销毁迁移，安装后需要重新录入组织和人员。
