# v1.3.1 修复导入排班卡死并简化上班/休息识别

## 修复

- 修复粘贴排班后点击「解析并导入」，遇到未匹配姓名时页面卡死的问题。
- 卡死原因是未匹配姓名弹窗使用阻塞队列，在主线程等待用户点击，导致弹窗本身也无法响应。
- 未匹配姓名处理改为 Kotlin 协程挂起等待，不再阻塞 UI 线程。
- 弹窗取消、关闭、选择忽略、选择已有人员、新增人员后都能正常继续导入。
- 同一个未匹配姓名在同一次导入中仍只处理一次。
- 上班/休息模式判断只看关键词：
  - 文本包含「休息」时按休息表处理；
  - 包含「上班」或未写明休息时按上班表处理；
  - 不要求必须出现「人员」二字。
