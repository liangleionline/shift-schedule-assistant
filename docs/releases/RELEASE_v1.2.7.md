# v1.2.7 新增人员后当前小组刷新修复

## 修复

- 在人员管理页切换到第二组或其他小组后，点击新增人员，保存后列表继续显示该小组，而不是跳回第一组。
- 新增人员弹窗中选择的所属班、所属小组会同步为页面顶部当前选中项。
- 编辑人员并调整到其他小组后，保存后自动切换并显示目标小组。
- 保存人员后只刷新当前人员列表，不再重建整个班/小组下拉框，避免选择状态被重置。
- 从首页重新进入人员管理页时，仍默认显示第一个班和第一组。

## 构建

- versionCode：11
- versionName：1.2.7
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。
