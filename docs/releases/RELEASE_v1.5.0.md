# v1.5.0 新增循环排班

## 新增

### 循环排班导入

首页新增「循环排班」入口，适用于按小组轮换上班/休息的场景。

流程：

1. 选择导入日期区间；
2. 设置几天一循环，例如 2 天；
3. 为循环内每一天选择当天上班的小组；
4. 自动生成日期区间内的循环排班预览；
5. 保存前可以逐天调整上班人员；
6. 确认后一次性写入排班数据。

示例：2 天一循环：

- 第 1 天选择 A 组上班；
- 第 2 天选择 B 组上班；
- 系统会在日期区间内按 A、B、A、B 自动循环。

### 每日排班微调

循环预览中每一天都有「调整」按钮：

- 可以勾选或取消具体人员；
- 可以临时给某天增加其他组人员；
- 可以临时移除某个人；
- 调整结果只影响所选日期，不改变循环规则本身。

### 首页操作区优化

- 原「导入排班」改为「粘贴导入」。
- 新增「循环排班」按钮。
- 设置、组织架构、人员管理调整到第二行，减少按钮拥挤。

## 其他

- 循环排班写入的是普通 WORK 排班记录，可在首页正常查看，也可用设置中的撤销导入回退。
- 每次循环排班保存前同样记录导入快照，最多保留最近 3 次撤销。
