# v1.6.0 全新视觉改版 + 首页新增「明日」排班

## 界面重设计

- 建立统一设计语言（Theme.kt）：主色渐变、圆角卡片、柔和投影、水波纹点击、胶囊按钮。
- 首页改为可滚动长页：
  - 顶部蓝紫渐变头部卡，显示应用名、当天日期与星期、当前班选择。
  - 白色周历卡：上一周 / 本周（点击回到今天并选中）/ 下一周，今天浅蓝高亮、选中深蓝。
  - 操作卡：粘贴导入、循环排班为实色胶囊；组织架构、人员管理、设置为浅灰描边胶囊。
- 组织架构、人员管理、排班设置三个页面统一为相同的渐变头部 + 卡片 + 胶囊按钮风格。
- 所有页面统一深色状态栏与浅色系统图标，并避让顶部状态栏。

## 首页新增「明日」排班

- 首页在「今日」排班卡片下方新增「明日」排班区块，充分利用下方空余空间。
- 今日、明日均左右两栏展示上班 / 休息人员，按小组分组，班长置顶高亮。
- 两栏标题卡均可点击，直接调整该日上班人员（勾选=上班，取消=休息）。

## 保留的能力

- 粘贴导入（上班/休息关键词识别、休息取反、模糊与同音字匹配、未匹配处理）。
- 循环排班（日期区间、循环天数、按天选上班小组、预览逐日增删）。
- 排班设置（撤销最近导入最多 3 次、清空指定时间段、清空全部）。
- 组织架构与人员的增删改、班长校验、多班多组。
