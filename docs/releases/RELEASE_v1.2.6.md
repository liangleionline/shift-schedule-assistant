# v1.2.6 默认小组与深色状态栏修复

## 修复

- 人员管理页当前已选择某个小组时，点击「新增人员」，弹窗中的所属小组默认选中当前小组。
- 修复新增人员弹窗初始化时 Spinner 自动回调，把所属小组重置成第一个小组的问题。
- 编辑已有人员时，仍默认选中该人员原属班和原属小组。
- 切换弹窗中的班时，小组会优先跟随页面当前小组；找不到时才默认第一个。
- 首页、组织架构页、人员管理页状态栏改为深色背景。
- 状态栏系统图标（时间、电池、信号等）使用浅色显示，避免白底白字看不清。

## 构建

- versionCode：10
- versionName：1.2.6
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。
