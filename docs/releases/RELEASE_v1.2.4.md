# v1.2.4 自动清理重复小组

## 修复

- App 启动和进入组织架构页时自动执行重复数据清理。
- 同一班内如果存在多个同名小组，只保留最早创建的小组。
- 重复小组中的人员会自动移动到保留小组；同名同职位人员会去重。
- 排班记录中失效或重复的人员 ID 会同步清理。
- 修复历史版本已经产生两个「第一组」后，覆盖安装仍然显示两个的问题。
- 保留 v1.2.3 的唯一创建、防重复点击和首次初始化保护。

## 安装说明

本次不需要先卸载。安装 v1.2.4 后打开 App，或进入「组织架构」页面，系统会自动把已有的重复「第一组」合并为一个。

## 构建

- versionCode：8
- versionName：1.2.4
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。
