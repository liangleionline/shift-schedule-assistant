# v1.0.1 启动闪退修复版

## 修复

- 修复 AndroidManifest 中启动 Activity 包名配置错误导致的打开即闪退问题。
- 补全传统启动图标资源，降低不同 Android 版本资源兼容风险。
- 修正周日历周切换基准日期，避免多次切换后定位错乱。
- 增加数据库异常迁移兜底，避免开发版本数据库结构变化导致启动崩溃。

## 构建

- versionCode：2
- versionName：1.0.1
- ABI：仅包含 `arm64-v8a`（64 位 ARM），不包含 32 位 ABI。

## 说明

该 APK 为 debug 签名测试包，可直接覆盖安装；如手机已安装 v1.0.0，因包名相同可直接升级。
