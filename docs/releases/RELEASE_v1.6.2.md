# v1.6.2 状态栏改为纯黑不透明

## 修复

- 修复在 targetSdk 36（强制 edge-to-edge）下 `statusBarColor` 被系统忽略，导致状态栏透明、露出浅色背景，白色时间/电池图标看不清的问题。
- 四个页面（首页、组织架构、人员管理、排班设置）统一退出 edge-to-edge，状态栏改为**纯黑不透明**，系统图标强制为白色，在任何配色下都清晰可读。
- 内容区由系统自动避让状态栏，移除原先手动计算的状态栏内边距，避免重复留白。
