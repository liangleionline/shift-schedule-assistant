# v1.0.0 初始版本

## 新增

- 安卓原生项目骨架（Kotlin + Room + Material Components）。
- 首页一周日期条，支持上一周/下一周切换。
- 首页上班、休息左右双栏。
- 按小组展示人员，班长自动置顶。
- 支持首次启动初始化班组、小组和班长。
- 支持粘贴多行排班文本。
- 支持「上班人员」「人员休息」关键词识别。
- 支持 `9月25日`、`10月1日`、`10.04`、`9.25` 等日期格式。
- 支持空格、逗号、全角逗号、顿号、句号、分号分隔姓名。
- 休息名单自动按全员取反得到上班名单。
- 支持别名规则、精确匹配、缺字匹配、近音匹配。
- 唯一模糊候选自动匹配并保存规则。
- 多候选或未知人员支持手动选择/忽略。

## 说明

当前版本为首个可继续开发的源码版本，建议在 Android Studio 中打开并完成 Gradle Sync 后运行。
