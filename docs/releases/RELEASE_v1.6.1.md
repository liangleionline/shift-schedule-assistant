# v1.6.1 设置「我的姓名」并在排班中加粗

## 新增

- 排班设置页新增「我的姓名」卡片，可输入、修改或清空自己的姓名。
- 姓名保存在本地（SharedPreferences），与班/组无关，全局生效。
- 首页「今日」和「明日」的上班、休息名单中，凡姓名与所设姓名一致的人员：
  - 字体加粗；
  - 使用主题强调色，便于一眼找到自己。
- 从设置页返回首页会自动刷新，无需重启。
