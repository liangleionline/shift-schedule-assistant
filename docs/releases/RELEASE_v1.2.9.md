# v1.2.9 修复组织架构小组列表高频闪烁

## 问题原因

v1.2.8 将组织页改为统一渲染后，部分 Android 机型在 Spinner 重新绑定 adapter、设置选中项或布局回调时，会异步触发 `onItemSelected`。即使选中的仍是同一个班，旧逻辑也会再次调用 `render()`，造成：

- 小组列表被反复清空并重建；
- 页面持续高频闪烁；
- 卡片频繁销毁，按钮无法稳定点击。

## 修复

- 班下拉框回调增加 id 判断：只有用户真正切换到不同班时才重新渲染。
- adapter 内容没有变化时不再重复创建和绑定 Spinner adapter。
- 增加渲染代次号，过期渲染任务不得再清空或重建小组列表。
- 保留 v1.2.8 的单一 renderJob、旧任务取消、Group id 去重机制，继续防止重复卡片。

## 构建

- versionCode：13
- versionName：1.2.9
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。
