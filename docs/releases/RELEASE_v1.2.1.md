# v1.2.1 组织架构刷新与重复数据修复

## 修复

- 修复修改班名后下拉框不实时刷新、必须退出重进才更新的问题。
- 修复新增小组可能因重复监听/重复回调创建两条相同小组的问题。
- 修复首次启动后默认「第一组」可能异常重复的问题。
- 修复多个同名小组编辑其中一个后界面显示混淆的问题。
- 修复首页、组织架构、人员管理中班组下拉框白底白字、看似没有内容的问题。
- 班、组、人员页面改为数据变更后主动重新加载，避免 Flow 重复发射导致重复写入。
- 人员管理页回到前台时自动刷新班、组和人员数据。

## 构建

- versionCode：5
- versionName：1.2.1
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。

## 说明

如果你在 v1.2.0 中已经产生了重复的「第一组」或重复班，本版本不会自动合并历史数据；安装后可手动删除重复项，后续新增不会再重复。
