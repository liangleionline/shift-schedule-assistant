# v1.5.1 日历返回今天与班信息入口优化

## 调整

### 首页日历

- 顶部日历中的“本周”改为可点击。
- 点击后立即回到当前日期所在周，并选中今天。

### 组织架构页

- 加宽班名下拉框，避免两个字的班名被挤压成竖排。
- 将顶部“改班名 / 新增班 / 删班”三个按钮合并为一个“编辑班信息”按钮。
- 点击“编辑班信息”后弹窗展示：
  - 修改班名
  - 新增班
  - 删除班
- “删班”文案统一改为“删除班”。

## 构建

- versionCode：19
- versionName：1.5.1
- ABI：仅包含 `arm64-v8a`（64 位 ARM）。
