# v1.2.2 班组/小组重复数据根治修复

## 修复

- 修复新增班组后退出页面再进入，班组变成两个的问题。
- 修复新增小组可能因页面回调或观察者重入导致重复的问题。
- 数据库层增加唯一约束：
  - 班名全局唯一。
  - 同一班下的小组名唯一。
- 新增班组/小组时先查询同名记录：如果已存在则直接复用，不再插入第二条。
- 首次初始化默认班、默认第一组时也改为唯一插入。
- 新增班、新增小组按钮在保存过程中临时禁用，避免重复点击或弹窗回调重入。

## 数据说明

本版本数据库版本升级到 v2。由于旧版本中可能已经存在重复班组/小组，覆盖安装后会使用销毁迁移重建本地数据库，旧的测试组织架构和排班数据会被清空，需要重新录入一次正式数据。
